## Beta notes

- **Renamed to Lumen Worship** — new app name across the installer, shortcuts, and in-app header.
- **First-launch welcome guide** — a short walkthrough appears the first time you open Lumen Worship; replay it anytime from Settings.
- **Present is smarter about a second monitor** — if one's connected, the audience view opens there automatically and your own screen stays usable; otherwise Present/F5 now goes real fullscreen (and the app menu bar no longer shows).
- **Auto-update toggle** — Settings now has a switch to turn automatic update checks on/off, with a live status line and a notification bell in the header.
- **Edit lyrics now edits everything** — the lyrics editor shows the same Title/Artist/Key/BPM/Category/Tags fields as "Add song" for songs you created.
- **Upload song improvements** — a downloadable sample `.txt` file and a guide explaining the `Title:`/`Artist:`/`Key:` header format that auto-fills those fields.

⚠️ This is a beta build — expect rough edges. Please report anything broken.
