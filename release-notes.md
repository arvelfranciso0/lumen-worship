## What's new

- **New Features** — Added compare, tour guide, new layout, transitions, notes, redo and undo, and drag-and-drop support when adding new songs to an existing lineup. Moved output detection to the header and added options to apply backgrounds by slide, by song, or to all slides.
- **Fix responsive** — Improved the system layout responsiveness to work properly across different screen sizes and prevent elements from overlapping.
- **Performance Improvement** — Improved system performance and optimized the application to run more smoothly on low-end devices.
- **Fix Presentation not Closing on External Screen** — Fixed an issue where the presentation output remained displayed on the external screen even after the system was closed.
